## Objetivo

Este repositório reúne os artefatos de planejamento do projeto **Módulo de Pedidos e Entregas**, desenvolvido na disciplina de Modelagem. O foco é documentar a Estrutura Analítica do Projeto (EAP) e, a partir dela, as atividades, durações e dependências necessárias para entregar o módulo.
